# Asset Research Skill

When a task needs an image, icon, font, fixture or other external resource:

- Search an appropriate legitimate online source.
- Prefer official sources and clearly licensed/free assets.
- Record source/license information when required.
- Download only the required asset into the project's normal asset directory.
- Never download executables, unknown scripts, credentials or suspicious files.
- Verify file type, size, reference path and application loading.
- Run the relevant build/UI test after adding the asset.
