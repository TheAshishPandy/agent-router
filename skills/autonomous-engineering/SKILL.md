# Autonomous Engineering Skill

1. Inspect architecture, README, configuration, dependencies, tests, TODOs and Git state.
2. Identify a concrete highest-priority incomplete task.
3. Implement the smallest coherent solution that preserves existing behavior.
4. Add or update tests.
5. Run build, tests, lint/type checks and relevant UI/browser checks.
6. Diagnose and fix failures instead of reporting them as complete.
7. For missing assets, use legitimate sources with clear licensing/free-use terms where possible.
8. Review the final diff and remove temporary files.
9. Never claim success without verification.
